# Bundled fonts

Any font file dropped in here is shipped with Cantara and offered in the font
settings, on the desktop and on the web alike.

* Supported formats: `.ttf`, `.otf`, `.woff`, `.woff2`
* **The file name is the family name.** `Open Sans.ttf` shows up as
  "Open Sans", so name the file exactly as the family should appear.
* `build.rs` picks them up automatically — nothing has to be registered.

Only ship fonts whose licence allows redistribution.
